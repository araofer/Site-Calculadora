Como dividir uma conta de restaurante?

Dividir uma conta entre amigos pode ser complicado, principalmente quando cada um consome itens de valores diferentes. Com nossa calculadora, você garante uma divisão justa e confere se o somatório bate com o total da nota.

Passo a passo

  • Total: Informe o valor que veio na nota fiscal.
  • Pessoas: Digite a quantidade de amigos na mesa.
  • Valores: Clique em "Inserir valores" para abrir os campos de cada pessoa.
  • Confira: O sistema dirá se falta dinheiro ou se o valor passou do total.

Dica para Gorjetas

Se a conta já inclui os 10% (ou 12%), use o valor final da nota no campo "Valor Total". Caso queira adicionar por fora, some a porcentagem ao valor antes de inserir aqui.
